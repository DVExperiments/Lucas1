# The Lucas Money Game

A four-week Success Avenue Money pilot for learners and facilitators. The app uses plain HTML, CSS and JavaScript. All assets use relative URLs, so the same files work on a GitHub Pages project site.

## Publish on GitHub Pages

1. Extract the ZIP. Copy its contents to the root of a GitHub repository, with `index.html` next to `assets/`. Include `.nojekyll` if your file manager hides it.
2. Commit to `main`. In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)** and save.
3. Open the link shown under Pages after deployment.

[GitHub Pages publishing source documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

For local testing, run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

## Try the pilot

- Start with Alex’s simulated car wash or select **Start your own game**. Choose a learning level, business mode and savings goal.
- Make the business decision, answer the quiz and submit a reflection. The scenario fills in sales and costs. With **My own business**, enter sales and costs in the money log yourself. Activity rewards stay separate from the business profit and bucket allocation.
- Open **Facilitator view** and review the submissions. Jamie has an example waiting. Record a check-in after all required activities are approved. This closes the week and opens the next.
- Return to **Learner view** and open **My progress** for check-in notes, approved points and finalised bucket allocations.
- In **Settings**, set a SAM lesson URL or adjust the simulated tax, weekly points bonus, bucket percentages and simulated savings match for newly opened weeks.

The pilot starts with fictional learners. Use nicknames and sample amounts for demos. The role switch and roster are local controls and everyone using the same browser profile can open them. There are no accounts, central database, shared classroom login, verified SAM completions or real money transfers. Browser data is specific to the device, browser profile and site URL. Clearing site data removes saved progress.
